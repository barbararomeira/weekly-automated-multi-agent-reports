# Sample run — pre-generated from synthetic data

These HTML files are committed snapshots showing what the system produces.
They were generated by running:

```bash
python run_weekly.py --mock --as-of 2026-05-21
```

against the synthetic data fixture (`fixtures/synthetic_cycles.csv`). `--mock`
swaps in fixed agent outputs so this runs identically on any machine with no
API key required.

## What's here

| File | What it shows |
|------|---------------|
| `sample_dashboard.html` | The customer-facing weekly KPI dashboard — 4 Plotly charts + the validated narrative panel at the top |
| `sample_fleet_view.html` | The cross-report index, showing one 🟢 card for the demo line |

## Reproduce yourself

```bash
git clone https://github.com/barbararomeira/weekly-automated-multi-agent-reports
cd weekly-automated-multi-agent-reports
pip install -e ".[dev]"
python run_weekly.py --mock --as-of 2026-05-21
open outputs/weekly_kpi_dashboard.html   # macOS
# or just open the file in your browser
```
